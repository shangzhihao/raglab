# raglab

This repository is a TypeScript lab for implementing and comparing different retrieval-augmented generation (RAG) techniques. It is a place to experiment with how systems retrieve relevant information and use it to answer questions.

## Setup

Install dependencies with `pnpm install`.

## Dataset

This project uses the [MultiHopRAG dataset](https://huggingface.co/datasets/yixuantt/MultiHopRAG). Store downloaded dataset files in `data/`.
